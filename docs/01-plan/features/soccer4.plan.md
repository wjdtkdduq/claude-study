## 1. 요구사항

### 1.1 허브 페이지 (soccer4.html)
- 헤더: "⚽ 축구4" + 부제
- 4개 카테고리 카드 (2×2 그리드)
  - 📝 축구 모의고사 — OPEN, soccer4-quiz.html 링크
  - 🏆 이상형 월드컵 — COMING SOON
  - 👕 베스트 11 — COMING SOON
  - ❓ 이스타 퀴즈쇼 — COMING SOON
- 호버 시 카드 상승 + 글로우 효과
- 반응형 (모바일: 1열)

### 1.2 모의고사 페이지 (soccer4-quiz.html)
- 제1회: 축구 TMI 상식 10문항
- 4지선다 선택 UI
- 진행률 바
- 정답/오답 즉시 피드백 + 해설
- 최종 점수 결과 화면 (5단계 등급)
- "← 목록으로" 복귀 버튼

### 1.3 공통 디자인 시스템
- 배경: `#0a0a0f`, 액센트: `#5b40ff`
- 카드: `rgba(16,16,26,0.95)`, border: `rgba(255,255,255,0.07)`
- border-radius: 12px(버튼), 20px(컨테이너)
- 폰트: system font stack

## 2. 성공 기준

- [ ] soccer4.html 열면 4개 카드 정상 표시
- [ ] 모의고사 카드 클릭 → soccer4-quiz.html 이동
- [ ] 10문항 순서대로 출제, 답변 중복 클릭 방지
- [ ] 정답: 초록, 오답: 빨강으로 즉시 피드백
- [ ] 진행률 바 문제 번호에 따라 업데이트
- [ ] 10문항 완료 후 결과 화면 (점수/등급/메시지)
- [ ] "다시 도전" 시 처음으로 리셋
- [ ] "← 목록으로" 시 허브 복귀
